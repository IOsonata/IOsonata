## Policy

- IOcomposer, plugins, branding and macOS signing/instance preferences must be complete before library compilation.
- Compilation errors in user-checkout IOsonata/TaktOS sources do not prevent installation from completing. Failed projects and logs must still be reported.
- The website launchers delegate to the IOsonata installers; do not duplicate installation logic there.
- LLVM is not installed/configured by IOcomposer development-tool installers, since the deployed Embedded CDT integration does not support the intended LLVM setup.
- Do not equate host-model tests with clean target builds or untested peripheral hardware.
- This is a release-preparation checklist, not a declaration of tag readiness.
