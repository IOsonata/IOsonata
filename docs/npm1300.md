# nPM1300 driver notes

nPM1300 control is implemented through existing IOsonata PowerMgnt and DeviceIntrf classes. Interfaces cover BUCK1/2, LDO1/2, load switches, GPIO, charger, ADC, interrupts, status and reset causes.

The charger must be disabled before modifying its charge-current registers. Valid charge-current requests are 32-800 mA in steps of 2 mA.

nPM1300 does not report battery state-of-charge percentage. Level() returns UINT16_MAX to indicate that no battery-specific estimator is configured. The generic battery profile does not contain the characterization needed for a reliable SOC calculation. Do not report a percentage derived only from instantaneous voltage.

Hardware and target compilation have not been run and remain release requirements.
