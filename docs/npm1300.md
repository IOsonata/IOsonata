# nPM1300 implementation and test requirements

The nPM1300 uses the existing IOsonata PowerMgnt, FuelGauge and DeviceIntrf interfaces. Implemented paths include BUCK and LDO programming, load switches, GPIO, charger configuration, ADC battery voltage and NTC, interrupt routing, PMIC status and fault registers, and ship mode.

## Silicon restrictions

The nPM1300 does not implement BATTERYDETECTED or BATDETECTED/BATLOST events. The Battery() interface cannot reliably indicate physical battery presence and returns false. Battery level is not a hardware value; Level() returns UINT16_MAX until a battery-specific fuel-gauge model is used. A percentage inferred from VBAT alone must not be represented as a measured fuel-gauge value.

Charge current is 32-800 mA in 2 mA increments and its register value is current / 2; MSB stores bits 8:1. The charger is disabled before modifying the current setting.

## Validation pending

A target build and board-level checks remain necessary, including charge current and termination voltage, BUCK/LDO rails, ship-mode controls, temperature and ADC scaling, event GPIO routing and I2C bus failures. No physical test has been run.
